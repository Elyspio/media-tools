# Purge Tool

Purge helps clean heavy build artifacts such as `node_modules`, `bin`, and `obj` from a chosen folder.

## Manual test

1. Open the app and navigate to **Purge** on the dashboard.
2. Select a folder containing a few test projects.
3. Click **Scan** and confirm the targets list looks correct.
4. (Optional) Toggle **Estimate size** and rescan to verify size output.
5. Click **Purge now** and confirm the targets are removed.
